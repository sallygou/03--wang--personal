# 王小明个人仓（教学模拟）

这是王小明的**个人仓**，属于《多人 AI Agent 协作工作区设计》课程作业中的个人工作空间。

## 定位

个人仓是成员自己的"独立工作室"，与公共仓（01-早鸟票公共仓）分离：

- 在这里接收来自公共仓交换区的任务包
- 在这里独立完成自己的任务、试错、迭代
- 成熟后再通过公共仓交换区或知识区对外输出

## 目录结构

| 目录 | 用途 |
| --- | --- |
| 01-输入/ | 接收来自公共仓交换区的任务包、他人交付物 |
| 02-任务/ | 当前正在进行的任务及工作底稿 |
| 03-生效区/ | 已完成并确认生效的产出 |
| 04-归档/ | 已完结或废弃任务的归档 |
| 09-日志/ | 工作日志、Agent 协作记录 |
